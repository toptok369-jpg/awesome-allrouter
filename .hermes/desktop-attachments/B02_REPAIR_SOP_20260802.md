
## 4. 测试用例（必须逐个过）

### 4.1 单 Panel Test
- 固定同一 motion clip
- 同一 canonical assets
- 输出：单 panel 视频
- QC：face similarity >= 0.92, wardrobe match >= 0.95, no extra character, no text

### 4.2 2-Panel Segment Test
- 两个 panel 必须有 image anchor
- 输出：2-panel 视频
- QC：跨 panel 连续性（人脸/服装/道具一致）

### 4.3 15-Shot Edit Test
- 必须先通过所有单 panel + 2-panel test
- 然后做 6-state edit
- 最终 QC：无漂移、无额外人物、无文字污染
